# Donor architecture map

These are architectural donors/reference implementations, not vendored dependencies and not claims of installation.

| Donor | Warforge use |
|---|---|
| Lokivellian Termux/Forge contracts | preflight/completion packets, registry discovery, honest health states, owned-process discipline, duplicate-port warnings, manifests |
| max-sixty/worktrunk | worktree isolation pattern for parallel coder seats |
| mvschwarz/openrig | role-based multi-agent team/orchestration concepts |
| NVIDIA/OpenShell | optional sandbox backend concept for autonomous seats |
| mksglu/context-mode | context/memory routing concepts |
| agent-skill repositories | portable `SKILL.md` operator instructions |
| GitHub + deterministic test harness | repository bridge and authoritative coding judge |

## Adoption rule

Borrow contracts and patterns first. Vendor or install an external donor only after its license, platform requirements, current source, and runtime behavior are inspected. The Warforge core remains transport-agnostic.
